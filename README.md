# MAVIS-EyeDisease

Explainable Deep Learning for Multi-Class Eye Disease Classification

- `ClassWorkOne/` — classification & fine-tuning notebooks (VGG16, ResNet, AlexNet, EfficientNet, MobileNet)
- `ClassWorkOne/compare-all-pretrained-eye-disease.ipynb` — all pretrained baselines in one run (DEFAULT, no freeze, 30h resume)
- Dataset: [gunavenkatdoddi/eye-diseases-classification](https://www.kaggle.com/datasets/gunavenkatdoddi/eye-diseases-classification)
